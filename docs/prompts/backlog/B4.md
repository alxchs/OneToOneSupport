Branch: ase/B4-npm-audit (confirme com git branch --show-current; se não estiver nela, pare). Você é executor.

## Entregas
1. Triagem das 24 vulnerabilidades listadas em 
pm audit (especialmente as 2 críticas).
2. Classificação para cada uma: se afeta a produção (app empacotado) ou apenas devDependencies.
3. Correção (atualização) de pacotes *apenas* onde não quebre o app. O que não puder ser atualizado vira ADR com justificativa.

## Regras específicas desta fase (cada uma vira teste que tenta VIOLÁ-LA)
- Uma atualização de pacote não pode quebrar testes E2E.
- Toda vulnerabilidade ignorada deve possuir uma justificativa rastreável.
